## Как заливать контент (3 способа)

### 1) Только файл
Отправьте боту документ / фото / видео **без подписи**.  
Бот вернёт ссылку. Пользователь получит только файл.

### 2) Файл + текст (подпись)
Отправьте файл **с подписью** (caption) — в Telegram это текст под файлом при отправке.  
Бот сохранит файл и текст.  
Пользователь по ссылке получит **файл вместе с этим текстом** (пароль, инструкция и т.д.).

### 3) Только текст
Отправьте боту **обычное текстовое сообщение** (не команду).  
Бот вернёт ссылку на текст.  
Пользователь после подписки получит этот текст (без файла).

Ссылка всегда вида:
```text
t.me/ИМЯ_БОТА?start=ХЭШ
```

## Чтобы бот не засыпал (Render Free)

### GitHub Actions (ПК можно выключить)

1. Render → скопируйте URL сервиса (`https://....onrender.com`).
2. GitHub → репозиторий → **Settings → Secrets and variables → Actions**.
3. Secret:
   - Name: `KEEP_ALIVE_URL`
   - Value: URL сервиса
4. Workflow `.github/workflows/keepalive.yml` должен быть в **корне** репозитория.
5. Вкладка **Actions** → раз в 5 минут идёт **Keep Render Awake**.

### Скрипт на ПК

```powershell
python keepalive.py https://ВАШ-URL.onrender.com
```

Окно не закрывать. Если ПК выключен — пинг не работает.

## Если бот «упал» / перезапустился на Free Render

Сами файлы лежат у Telegram.  
В базе бота хранятся только `file_id` + текст + хэш ссылки.  

На Free Render база может обнулиться после деплоя — тогда старые ссылки перестанут работать, нужно залить контент заново.

## Проблемы

| Проблема | Решение |
| --- | --- |
| Нет ответа | Render Live? Локальный бот выключен? |
| Нет админки | Пишете не с админ-аккаунта |
